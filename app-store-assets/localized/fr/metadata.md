## Description
`Cat Scratches est une extension Safari pour envoyer du texte web propre vers Drafts. Elle peut aussi utiliser la feuille de partage pour Notes, Mail, Messages et d'autres apps. Extrayez automatiquement le corps principal d'un article ou sélectionnez du texte pour capturer un passage.

Utilisez-la pour :
• Envoyer le titre, l'URL source et le texte vers Drafts
• Enregistrer des captures dans Notes ou d'autres apps avec la feuille de partage
• Convertir les captures en Markdown lisible
• Choisir des modèles, des tags et des réglages de nettoyage

Fonctionnement :
1. Activez l'extension Cat Scratches dans Safari
2. Ouvrez une page web dans Safari
3. Lancez Cat Scratches
4. Relisez ou modifiez la capture dans Drafts, Notes ou une autre app

Cat Scratches ne lit une page que lorsque vous lancez l'extension. Elle ne suit pas l'historique de navigation et ne collecte pas de données. Le code source est disponible sur https://github.com/ddegner/cat-scratches.`
