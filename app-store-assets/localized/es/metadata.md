## Description
`Cat Scratches es una extensión de Safari para enviar texto limpio de sitios web a Drafts. También puede usar la hoja de compartir para Notas, Mail, Mensajes y otras apps. Extrae automáticamente el cuerpo principal del artículo o selecciona texto para guardar un pasaje.

Úsalo para:
• Enviar el título, la URL de origen y el texto a Drafts
• Guardar capturas en Notas u otras apps con la hoja de compartir
• Convertir capturas a Markdown legible
• Elegir plantillas, etiquetas y ajustes de limpieza

Cómo funciona:
1. Activa la extensión Cat Scratches en Safari
2. Abre una página web en Safari
3. Ejecuta Cat Scratches
4. Revisa o edita la captura en Drafts, Notas u otra app

Cat Scratches solo lee una página cuando ejecutas la extensión. No rastrea el historial de navegación ni recopila datos. El código fuente está disponible en https://github.com/ddegner/cat-scratches.`
