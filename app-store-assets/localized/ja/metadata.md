## Description
`Cat Scratchesは、SafariのきれいなWebテキストをDraftsへ送るためのSafari拡張機能です。共有シートを使って、メモ、メール、メッセージ、ほかのアプリへ送ることもできます。記事本文を自動抽出するか、選択した文章をクリップできます。

できること：
• ページタイトル、元URL、本文をDraftsへ送信
• 共有シートでメモやほかのアプリに保存
• 読みやすいMarkdownに変換
• テンプレート、タグ、クリーンアップ設定を選択

使い方：
1. SafariでCat Scratches拡張機能を有効にする
2. SafariでWebページを開く
3. Cat Scratchesを実行する
4. Drafts、メモ、またはほかのアプリで内容を確認・編集する

Cat Scratchesは、拡張機能を実行したときだけページを読み取ります。閲覧履歴を追跡せず、データも収集しません。ソースコードは https://github.com/ddegner/cat-scratches で公開されています。`
